TINGGE · PLAYER · 3 DIRECTIONS

播放页，三个方向

同一首歌、同一套信息，三种结构：光学玻璃把封面当发光体，唱片档案把它当印刷品，声场仪表把它当信号源。黄色标签只是选型用的方向名，不是产品文案。

A · 光学玻璃材质与光
现有语言的强化版
封面 338pt 悬浮玻璃，极光只做底色；
进度是 1px 发光线，控件留白最大。
B · 唱片档案排版与纸
最不像播放器的一版
封面是印刷封套（竖排歌名 + 编号），
歌词用宋体居中偏左，靠一条竖线标当前行。
C · 声场仪表数据与刻度
把解码状态摆到台面
频谱占主位，缓冲/码率/采样/延迟四格读数，
播放键做成设备按键。
A 的第二稿进度改成封面外圈的细环，时间贴在环上；封面随播放缓慢自转（减弱动态效果时静止）。
B 的第二稿歌词改成双栏对开（原文/译文），左栏窄、右栏宽，像歌词本跨页。
C 的第二稿频谱换成一条滚动示波线，读数改为纵向刻度尺，更像硬件面板。
可交互　三份 HTML 都能点：播放/暂停会换图标，歌词行可点选。 已验证　删除 android/ 与安卓流水线后，tsc 零错误、三语 664 键一致。 说明　曲目《夜航》为示例数据，不指向真实作品；封面为程序化材质。
